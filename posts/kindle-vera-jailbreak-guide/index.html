Kindle Véra 越狱中文教程

写于2026年8月14日
Warning

越狱有风险，可能影响设备稳定性、保修与安全性。本文是对 KindleModding Véra 官方教程 的中文整理，不保证适用于未列出的机型或固件。开始前请核对机型和完整固件号，并自行备份本地书籍与文档。

Véra 是什么

Véra 是 Ava 和 sparklerfish 于 2026 年 8 月 10 日发布的 Kindle 越狱方案。它最大的特点是全程在 Kindle 上完成，不需要电脑和 USB 数据线：用内置浏览器打开网页，下载两本专用电子书，按指定方式保存一套阅读主题，再打开 Véra 书籍即可触发越狱。

发布公告称，Véra 可用于未注册和黑名单设备；越狱流程会一并安装 Hotfix，并自动阻止 OTA 更新。也正因为全程需要联网，操作前先防住自动更新，比后面任何一步都重要。作者发布公告 里也明确强调了这一点。

Note

Véra 不适合“先试试看”。一旦 Kindle 在流程中自动升级到不支持的固件，通常不能在未越狱状态下退回旧版。因此，下文先讲容量填充和固件核对，再碰浏览器。

开始前：先阻止自动更新

Véra 的流程必须使用 Wi-Fi，而 Kindle 在连网、打开商店或重启时都有可能下载固件更新。官方建议在开始前先把可见存储填满，只保留很少的空闲空间，使更新包无法完整下载。

请先按 KindleModding 的防自动更新教程 填充 Kindle 存储。完成后再检查根目录：如果已有以 .bin 结尾的更新文件，或 update.bin.tmp.partial 一类临时文件，先删除它们。

Caution

填充存储是本次越狱的前置保护，不是可选优化。Véra 成功后官方流程会自动阻止 OTA，此时才可以删除 filler files 回收空间；但在这之前不要为了腾空间而提前清空它们。

安装步骤

1. 再次确认固件号

回到设备信息页，确认完整版本没有看错。后面下载页会要求选择这个版本，选错会拿到不匹配的 Véra 书籍。

2. 打开 Kindle 内置浏览器

在首页点击右上角三点菜单，进入：

打开下面的网址：

如果网站暂时打不开，不要反复下载或随意换镜像。先确认 Wi-Fi 正常，再稍后重试官方地址。Véra 的两个文件必须来自官方页面，不要使用群聊或网盘里流传的同名书籍。

3. 选择机型和完整固件

网站会读取 Kindle 的屏幕分辨率，部分情况下能够自动收窄可选机型。如果同一分辨率对应多个型号，手动选自己的机型；随后在下拉框中选择前面记下的完整固件号。

如果你的版本位于官方声称的总体范围内、却没有出现在下拉列表里，官方建议尝试最接近的上下相邻版本，但并不保证成功。这里更稳妥的做法是先到 KindleModding 社区求证，不要连续测试多个版本的书籍。

4. 下载两本书，然后退出浏览器

确认机型和固件后，网页会显示两个下载链接：

  1. Font Calibration；
  2. 与当前机型和固件绑定的 Véra 书籍。

两本都要下载。每次出现确认框都点击确认，等下载完成后点击浏览器右上角的 X 退出。

退出浏览器后等待 2 至 3 秒，再去图书馆打开书籍。这样可以避免 Kindle 的界面焦点还停留在浏览器，误点到错误的项目。

Warning

现在不要关闭 Wi-Fi。直到 Véra 书籍执行完成、界面重启为止，网络仍是流程的一部分。

5. 打开 Font Calibration，并进入 Aa 菜单

在图书馆打开刚下载的 Font Calibration。轻触屏幕上方调出阅读工具栏，点击 Aa。

6. 设置字体参数

进入底部的 Font 菜单，依次设置：

设置项值
Font FamilyBookerly
Bold0
Size可选的最大值

这些值需要精确匹配，不要按自己的阅读习惯改动。它们不是为了改变阅读体验，而是为下一步保存的主题准备特定状态。

7. 设置行距

不同固件的 Aa 面板名称略有不同：

  • 如果顶部显示 Layout，进入后把 Spacing 设为中间档；
  • 如果底部直接显示 Spacing，把 Line Spacing 设为 2，然后点左上角返回。

8. 保存当前主题

进入顶部的 Themes。如果你的界面将主题放在其它入口，仍以“保存当前阅读设置”为目标：点击 Save current settings，然后再次点击 Save 完成保存。

保存后，连续点击左上角 Home 或 Library 三次，完全退出 Font Calibration。

9. 打开 Véra 书籍并等待界面重启

在图书馆点击与自己设备匹配的 Véra 书籍。正常情况下，屏幕左上角会先出现滚动文本，随后弹出：

等待图形界面重新启动并回到系统。期间偶尔出现 Application Error 提示可以忽略。

如果停留在某个界面超过 10 分钟，长按实体电源键，在重启选项出现后选择重启。官方说明这一步是安全的；重启后不要直接重置设备，先检查是否已经回到 Kindle 主界面。

10. 清理并进入后续配置

图形界面重启成功后，可以删除 Véra 和 Font Calibration 两本书。然后：

  1. 检查 Kindle 根目录，删除已有的 .bin 更新文件；
  2. 确认没有 update.bin.tmp.partial 一类下载残留；
  3. 再删除之前用于填满存储的 filler files；
  4. 按 What’s Next 继续安装 scriptlets、homebrew 或 KOReader。
Tip

Véra 的官方流程说明 OTA 已被自动阻止，并且发布公告称 Hotfix 已随越狱安装。因此，除非官方后续教程明确要求，否则不需要把旧版教程里的“手动安装 Hotfix”或“手动重命名 OTA 二进制”步骤叠加执行。

常见问题

Véra 网站打不开或下载失败

先检查 Wi-Fi 和浏览器能否打开其他 HTTPS 网站。不要从非官方渠道寻找“备用书籍”。网页和电子书是按机型、分辨率和固件组合准备的，错误文件更难排查。

我的固件不在下拉框里

优先检查完整版本号是否抄错。只有在版本落于官方总体支持区间、但确实没有精确选项时，才考虑最接近的相邻版本；这属于官方标明“不保证成功”的兜底方案。

打开 Véra 书后没有任何反应

回头逐项核对第 5 至第 8 步：必须先打开 Font Calibration，字体为 Bookerly、粗体为 0、字号最大、行距正确，并且保存过当前主题。少一个步骤，Véra 书就可能不触发。

RESTARTING GUI 停留超过 10 分钟

按住实体电源键，出现重启选项后重启 Kindle。不要在这个阶段执行恢复出厂设置。

公开资料能证明的原理

Véra 的公开入口网页提供了一部分可以直接验证的事实：

  1. 它按屏幕分辨率识别候选设备。网页读取 Kindle 的逻辑屏幕尺寸和像素比，先确定分辨率，再在共享分辨率的设备之间要求手动选择。
  2. 它按完整固件下载专用载荷。网页会动态生成形如 机型-完整固件-jb.azw3 的下载地址，同时下载通用的 fontcal.azw3。
  3. 阅读设置和已保存主题是触发前提。官方流程要求先用 Font Calibration 把字体、字号和行距写入阅读偏好，再将当前状态保存成主题，最后才打开 Véra 书。
  4. 可观察到的结果是 GUI 重启。Véra 书触发后，系统显示 RESTARTING GUI，随后重新加载图形界面；越狱后的 Hotfix 与 OTA 防护由流程一并处理。

当前不能确认的部分

公开教程没有披露具体的内存漏洞、解析器缺陷或提权实现。Font Calibration 与主题保存显然是利用链的一环，但现有公开材料不足以证明它究竟利用了字体渲染、主题序列化还是其它系统组件。

因此，比较准确的说法是“Véra 利用设备专用电子书和预置阅读主题触发越狱”；把它直接称为“字体漏洞”或“主题漏洞”都属于过度推断。等维护者发布技术 write-up 或源码后，再补充底层机制会更稳妥。
