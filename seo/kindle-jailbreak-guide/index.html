Kindle 越狱怎么选：Véra 与 SpringBreak 中文对照

直接回答：先查机型和完整固件，再选教程

Kindle 越狱不能只看“第几代”或固件的大版本号。开始前应先确认机型代码、完整固件号、注册状态和 USB 连接方式，再使用 KindleModding Jailbreak Wizard 做最终核对。

本站目前有两篇经过整理的中文教程：

  • 设备能在 Véra 官方页面中选到精确的机型与固件，并希望直接在 Kindle 上完成操作：阅读 Kindle Véra 越狱中文教程。
  • 设备属于 KT5、PW5、KT4 或 PW4，固件与 SpringBreak 表格完全一致，并且能以传统 USB 大容量存储方式连接电脑：阅读 Kindle SpringBreak 越狱中文教程。

如果两个方案都不匹配，不要尝试用“最接近”的型号或随意降级。原厂未越狱设备通常不能直接降级，应回到官方向导查找其他方案或等待支持。

哪些设备优先核对 Véra

Véra 当前面向 KT5、PW5、KT6、PW6、CS、KS 和 KS2 的受支持固件，官方说明覆盖到 5.19.6，但不是每个机型都支持这一区间内的每个构建。真正有效的判断标准，是 Véra 下载页能否同时选到你的机型和完整固件号。

Véra 的优势是不需要电脑或数据线，操作全部在 Kindle 上完成。代价是流程必须联网，因此在打开浏览器前，需要按官方方法填充存储并删除可能已经下载的更新文件，避免设备在越狱过程中自动升级。

哪些设备优先核对 SpringBreak

SpringBreak 的官方前提更窄，但判断更明确：

机型支持固件
KT5、PW5、PW5SE5.19.2 或 5.19.2.0.1
KT4、PW45.18.1.1.1

此外，设备必须已注册，并能通过 USB 以传统大容量存储方式挂载。如果连接电脑后显示的是带“断开连接”按钮的 MTP 界面，就不应继续使用 SpringBreak。

SpringBreak 会创建大量嵌套目录来保留修改后的商店缓存。越狱成功后必须再次运行安装器执行清理，否则设备启动可能明显变慢。

两个方案都支持时怎么选

KT5 或 PW5 的部分固件可能同时落入两个方案的范围。这时没有统一的“最好”答案：

  1. 先用官方向导确认两个入口都明确支持你的完整版本。
  2. 希望不连接电脑，并能严格完成防更新步骤，可优先阅读 Véra 流程。
  3. 设备已注册、USB 大容量存储正常，并更愿意使用电脑端安装器，可阅读 SpringBreak 流程。
  4. 任一前提不确定时，停止操作并到 KindleModding 社区核对，不要连续试多个利用链。

开始前共同检查

无论选择哪一个方案，都先完成以下检查：

  1. 在“设置 > 设备选项 > 设备信息”记录完整固件号。
  2. 用序列号前缀确认机型代码，不要只按商品名称判断。
  3. 备份本地书籍和文档。
  4. 删除根目录中已有的 .bin 更新文件或 update.bin.tmp.partial。
  5. 按官方防自动更新指南处理存储空间，再进行任何联网步骤。

常见问题

固件号只差最后一段，可以直接试吗？

不建议。5.19.2 与 5.19.2.0.1 可能是不同构建，兼容性应以官方页面的精确选项为准。没有对应选项时，先向社区确认。

Kindle 越狱后能直接降级吗？

越狱后可以在满足工具和固件要求时按专门教程降级；未越狱的原厂设备通常不能把“先降级”当成进入受支持版本的方法。

越狱后还需要安装 Hotfix 吗？

SpringBreak 官方说明 Hotfix 已预装；Véra 当前流程也会一并处理 Hotfix 和 OTA 防护。不要把其他旧教程的步骤重复叠加，完成后按各自教程进入后续配置。

越狱后可以做什么？

常见用途包括安装 KOReader、KUAL、脚本和其他 homebrew。先确认 OTA 已阻止，再按官方 What’s Next 指南逐项安装。日常阅读方面，也可以参考本站的 KindleRSS 使用体验。
